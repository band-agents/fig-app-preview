# FIG — app preview

**The app: https://band-agents.github.io/fig-app-preview/**

The FIG mobile app, compiled for the browser. The same code that runs on a phone, talking to the
live FIG backend: FIG's real catalogue from Shopify, a real bag, and a real checkout with an
Egyptian address.

Pay with **cash on delivery** to place an order end to end. Card and wallet payments use Paymob's
native payment sheet, which exists only in the Android and iOS apps, so the browser does not offer
them.

Orders placed here land in the Medusa admin, not in Shopify, so they reach no one's warehouse.
Cancel them there when you are done.

Built by [BAND](https://github.com/band-agents) from `band-agents/FIG-app`.
